# «Мафия под прицелом»

Статический сайт клуба на React, TypeScript и Vite. После сборки сайт не требует backend-сервера или базы данных: содержимое хранится в JSON-файлах репозитория, фотографии — в `public/`.

## Запуск и сборка

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

Vite сохраняет готовый сайт в `dist/`. Файл `render.yaml` задаёт команду сборки, папку публикации и перенаправление внутренних адресов на приложение.

## Страницы

- `/` — информация о клубе, стоимости и записи, фотографии и цитата.
- `/gallery` — галерея с просмотром фотографий.
- `/leaderboard` — поиск и сортировка рейтинга.
- `/quotes` — архив фраз, поиск, фильтр и случайная цитата.

Подробная инструкция по обновлению данных без изменения кода находится в [OWNER_GUIDE.md](./OWNER_GUIDE.md).

## Где менять данные

- `src/data/site-info.json` — название, город, VK, стоимость и пояснения.
- `src/data/gallery.json` — подписи и ссылки на фотографии.
- `src/data/leaderboard.json` — статистика игроков.
- `src/data/quotes.json` — цитаты.
- `public/uploads/events/` — файлы фотографий.

Галерея использует лёгкие миниатюры (`thumbnail`) в сетке и оптимизированное изображение (`src`) в просмотрщике. После изменения JSON локальная сборка проверяет обязательные поля и типы значений. При ошибке сборка сообщит, в каком файле и поле проблема. Опциональные поля `date`, `dateLabel`, `thumbnail`, `caption`, `event`, `featured`, `note` можно не заполнять.

## Важные ограничения

- Расписание клуба изменчиво. На сайте указано следить за анонсами ВКонтакте — конкретные даты не зашиты в страницы.
- Адрес места встреч и телефон не добавлены: этих сведений не было в исходных материалах.
- Рейтинг оставлен пустым до получения реальной статистики.
- В галерее использованы только предоставленные клубные фотографии. Даты мероприятий неизвестны, поэтому они отмечены как архивные.
- Контент сайта не записывается посетителями и не отправляется на сервер. Чтобы опубликовать обновление, измените файлы проекта и задеплойте обновлённую версию.
