# Как обновлять сайт клуба

Для обычного обновления контента не нужно знать React или TypeScript. Меняйте JSON-файлы и добавляйте фотографии, затем отправляйте изменения в GitHub. После публикации нового коммита Render соберёт сайт заново.

## Добавить фотографии

1. Создайте папку для мероприятия внутри `public/uploads/events/`, например `event-03`.
2. Скопируйте туда фотографии. Используйте WebP, если он доступен, или JPG; называйте файлы латиницей: `photo-01.webp`, `photo-02.webp`. Для крупных изображений создайте облегчённую миниатюру с суффиксом `-thumb.webp`.
3. Откройте `src/data/gallery.json` и добавьте объект мероприятия в начало списка, чтобы новая встреча была выше старых:

```json
{
  "id": "event-03",
  "event": "Игровой вечер",
  "date": "2026-11-04",
  "dateLabel": "4 ноября 2026",
  "photos": [
    {
      "src": "/uploads/events/event-03/photo-01.webp",
      "thumbnail": "/uploads/events/event-03/photo-01-thumb.webp",
      "alt": "Участники клуба за игровым столом",
      "caption": "Игровой вечер в Калуге"
    }
  ]
}
```

Дата должна быть в формате `ГГГГ-ММ-ДД`. Если точная дата неизвестна, укажите `"date": null` и подходящую подпись `dateLabel`. Для нескольких фотографий добавьте ещё объекты в `photos`. Не забудьте запятые между объектами JSON.

## Добавить цитату

Добавьте объект в массив `src/data/quotes.json`:

```json
{
  "id": "quote-002",
  "text": "Текст фразы участника",
  "author": "Имя или игровой псевдоним",
  "date": null,
  "dateLabel": "Дата, если известна",
  "event": null,
  "featured": false,
  "note": ""
}
```

У каждой цитаты должен быть уникальный `id`. Чтобы выделить фразу в блоке главной страницы, измените `featured` на `true`. Если дата или мероприятие неизвестны, оставьте `date` или `event` равными `null`.

## Обновить рейтинг

Добавьте игрока в массив `src/data/leaderboard.json`:

```json
{
  "id": "player-001",
  "name": "Имя или игровой псевдоним",
  "games": 0,
  "wins": 0,
  "points": 0
}
```

`games`, `wins` и `points` — целые неотрицательные числа. Процент побед сайт рассчитывает автоматически как количество побед, делённое на количество игр. Используйте статистику и правила подсчёта очков клуба; сайт не придумывает их.

## Обновить сведения о клубе

В `src/data/site-info.json` можно изменить название, город, ссылку на сообщество, цену и текстовые пояснения. Ссылка `vkUrl` должна вести на `https://vk.ru/...` или `https://vk.com/...`.

## Проверить и опубликовать изменения

Если на компьютере установлен Node.js:

```bash
npm install
npm run build
```

Если сборка завершилась без ошибок, сохраните изменённые JSON-файлы и изображения в GitHub. Render использует `npm install && npm run build` и публикует папку `dist`. Не добавляйте фотографии в `dist` вручную: содержимое `public/` копируется туда при сборке.
